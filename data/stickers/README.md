# 本地表情包

把图片放进这个目录，文件名（不含扩展名）就是表情 id。

支持：`.png` `.jpg` `.jpeg` `.gif` `.webp`

示例：

- `开心.png` → id `开心` → 模型写 `[[sticker:开心]]`
- `委屈.webp` → id `委屈` → 模型写 `[[表情:委屈]]`

仓库里预置了几张简易色块表情（开心/无语/委屈/哼/摸摸/晚安/你好/吃瓜），方便开箱能发出去。
换成你自己的图：同名覆盖即可。

管理员也可在 QQ 里**带图**发送：`收藏表情 开心`（或 `/收藏 开心`），会写入本目录；运行中的 bridge 会立刻刷新列表。

手动改完图片后重启 `pnpm bridge` 也会刷新列表。

人设提示会鼓励她「心情合适时适当插一张」，每句最多一张。
