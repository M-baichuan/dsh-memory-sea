记忆海 · 社交技能速查
====================

发「技能」或「/技能」可在 QQ 里看菜单。

1) 小约定
---------
  约定 30分钟后 喝水
  约定 明天20:00 交材料
  约定 周五 记得打电话
  看看约定
  取消约定 / 取消约定 1
  → 到点私聊提醒（不会在群里喊）

2) 悄悄话
---------
  群里发：悄悄话：今天有点累
  或：/悄悄话 今天有点累
  → 群里只回「嗯。」之类，正文只私聊回你

3) 表情包导演
-------------
  配个表情 无语
  /表情 开心
  表情列表
  → 从本地 data/stickers 里挑最贴的一张发出去

4) 回看切片
-----------
  回看 上周说烦的事
  你还记得 火锅
  → 从记忆海捞几条碎片，用人设口吻轻声复述（不逐字笔录）

5) 口味地图
-----------
  口味地图
  我喜欢 火锅
  我不喜欢 香菜
  忘掉口味 香菜
  → 闲聊里提到喜欢/讨厌也会悄悄记一点，注入对话但不当人生档案

6) 眼睛 + 加密保险柜
--------------------
  看看外面 口令
  眼睛相册 口令
  再看一眼 1 口令   （私聊发原图）
  删除眼睛 1 口令
  → 需 pnpm eye；口令见 config social.eye.secret
  → 不带口令当闲聊，不会报「口令不对」
  → 详见 docs/记忆海-眼睛说明.txt

7) 空间动态（管理员）
--------------------
  选择发动态类型 / 发条动态 日常
  确认发动态 / 取消动态 / 看看草稿

8) 人设 / 配音（管理员）
------------------------
  /人设列表  /人设 御姐宠  /人设重载
  /配音  /配音 可莉
  用户说「用语音回复」才念（需 pnpm tts）

  "skills": {
    "promises": true,
    "whisper": true,
    "stickerDirector": true,
    "recallSlice": true,
    "tasteMap": true,
    "eye": true
  }
