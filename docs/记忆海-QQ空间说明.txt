记忆海 · QQ 空间动态（草稿确认 + 类型选择）
==========================================

不会自动发说说。只有管理员指令才会走流程。

选类型（类似 /配音）
--------------------
  选择发动态类型
  /动态类型
  选择发动态的类型

会列出：
  1. 心情 — 轻情绪、碎碎念
  2. 日常 — 生活小事、随手记
  3. 想念 — 淡淡的想念（克制）
  4. 吐槽 — 轻吐槽、带点脾气
  5. 晚安 — 夜里收工/睡前
  6. 早安 — 早上醒来随口一句
  7. 随想 — 不定主题、随手一想

按类型生成草稿
--------------
  /动态类型 心情
  选择发动态类型 2
  发条动态 日常 下雨了想喝热饮
  发条动态 想念

确认 / 取消
-----------
  确认发动态    （或：确认发布 / 发布动态 / 就发这个）
  取消动态      （或：取消发布 / 不要发了）
  看看草稿

配置（config.json → social.qzone）
---------------------------------
  "qzone": {
    "enabled": true,
    "ugcRight": 4
  }

  ugcRight:
    1  = 所有人
    4  = 好友（推荐）
    64 = 仅自己

注意
----
  · 需要 NapCat 且支持 send_qzone_msg
  · 发布失败时草稿还在，修好后可再「确认发动态」
  · 发布成功会写一条低权重 chat_noise（如「某日发过『想念』类说说」），闲聊可淡淡接上
  · 改配置后需重启 bridge
